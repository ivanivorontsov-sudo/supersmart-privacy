Политика конфиденциальности браузера «Тихо»

Дата вступления в силу: 16 октября 2026 г. Разработчик: Иван Воронцов (org.ivanivorontsov.tiho).

Коротко

«Тихо» — браузер. Разработчик не получает ваши данные: в приложении нет учётных записей, рекламы и аналитики, телеметрия движка Gecko отключена.

Что хранится на устройстве

История, закладки, вкладки, настройки и данные сайтов (cookies, хранилища) хранятся только на телефоне. Удаление приложения удаляет их.

Куда уходят данные при работе

  • Сайты, которые вы открываете, получают ваш IP-адрес и обычные данные браузера, как и в любом другом браузере.
  • Поисковая система, выбранная вами (по умолчанию DuckDuckGo; также Яндекс, Google, Startpage, Brave, Mojeek), получает ваши поисковые запросы.
  • DNS через HTTPS — по умолчанию выключен. Если включить, имена сайтов отправляются выбранному провайдеру: Mozilla (Cloudflare), Quad9 или AdGuard DNS.
  • Обновления списков фильтров и приложения загружаются с GitHub (raw.githubusercontent.com, сервис GitHub, Inc., США), при этом GitHub видит ваш IP-адрес.
  • Дополнения загружаются с addons.mozilla.org (Mozilla) только когда вы их устанавливаете.

Разрешения

Камера, микрофон и местоположение запрашиваются только когда сайт просит к ним доступ, и выдаются сайту только с вашего согласия. Установка пакетов нужна для обновления самого браузера. Все разрешения можно отозвать в настройках Android.
